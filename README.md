Repositorio académico de Sheilyn Colina: ejercicios de Python, estadística, estructuras de datos y métodos numéricos. Complementa el portafolio aplicado; no representa una biblioteca lista para producción.

## Uso

Selecciona un ejercicio y revisa sus imports y rutas antes de ejecutarlo. Los scripts pueden depender de archivos locales; todavía no existe un entorno único validado para todo el repositorio. Los archivos de temperatura requieren revisar fuente, periodo y unidades antes de reutilizarlos.

## Organización

La carpeta `Analisis de datos - Copy/` duplica los archivos de `ANALISIS_DE_dATOS/` y se retira en esta revisión. Se conservan los ejercicios originales. Las distintas hojas de temperatura no se consolidan sin verificar su contenido y procedencia.
